# Candidate PR Audit Checklist

Use this compact checklist after reading an authored issue's body and timeline.

## Per issue

- [ ] Confirm viewer login and issue authorship.
- [ ] Read the complete current body and comments.
- [ ] Enumerate linked PRs from timeline/cross-references, not only issue text.
- [ ] Separate viewer comments from bot/triage/maintainer activity.
- [ ] Check whether the issue body cites moved or stale source paths.
- [ ] Check for newer duplicate or reproducing issues.

## Per candidate PR

- [ ] Author and ownership.
- [ ] Current state: open/closed/merged/draft.
- [ ] Base branch, head SHA, mergeability, and latest update.
- [ ] Latest comments and formal reviews.
- [ ] Unresolved requests or review blockers.
- [ ] Required/failed/pending checks.
- [ ] Whether the PR still applies to current main.

## Decision rubric

Actionable only if a verified viewer comment/edit/fix would advance the thread: stale evidence, unanswered direct question, incomplete viewer commitment, or viewer-owned PR blocker.

No action for bot summaries, duplicate labels, generated graphs, status transitions, product decisions awaiting maintainers, requests aimed at another author, or already-addressed feedback.
