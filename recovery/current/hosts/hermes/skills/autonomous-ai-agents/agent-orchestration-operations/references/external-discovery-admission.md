# External workflow discovery admission cost

Use this evidence when considering automatic skill/plugin catalog searches during orchestrator intake. It records a measured no-change decision, not a permanent ban; rerun the gate when concrete downstream evidence could change the result.

## Admission contract

Broad discovery is an optional candidate source inside the existing outcome-first comparison, never a second task authority, automatic installer, or default per-message step. Search only when a concrete capability gap or plausible named candidate can change the solution. Trivial, repetitive, settled, and adequately owned work should not pay discovery cost.

Predeclare the gate before searching:

- no install, enablement, or live configuration during discovery;
- popularity and source claims cannot admit a candidate;
- promotion requires full intake, behavior tests, independent verification, rollback, and explicit authority;
- admit only when a candidate produces a materially better verified result or avoids more implementation and maintenance cost than discovery, verification, prompt, and recurring maintenance consume;
- retain/simplify/no-change remains a valid outcome.
