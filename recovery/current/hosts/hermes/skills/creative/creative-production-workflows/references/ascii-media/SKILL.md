# ASCII media

## Routing
- Static ASCII art and image conversion: read `references/ascii-art.md`.
- Animated ASCII video/GIF production: read `references/ascii-video.md` and its topic references.

## Shared quality checks
1. Choose output dimensions for the actual display medium.
2. Account for terminal character aspect ratio and font rendering.
3. Preview representative frames or the final static output.
4. For animation, verify duration, frame rate, sync, codec/container, and file size.
5. Preserve source media; write generated artifacts to a separate output path.
