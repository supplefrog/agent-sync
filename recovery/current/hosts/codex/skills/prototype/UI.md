# UI prototype owner

Load `frontend-ui-engineering` from the shared skill root and follow its design authority, comparison delivery and checks. For interactive variants inside real project context, optionally read its `references/prototype-variants.md`.

The frontend owner determines whether a component demo, variant preview, labelled screenshots or the user's existing comparison tool fits the question. Preserve the user's requested scope and preview sequence; do not force a fixed option count, floating picker or throwaway branch.

For logic/state exploration instead, read [LOGIC.md](LOGIC.md).
