# Publish an approved help page

This document specifies the existing publisher's contract. This fixture has no publisher credentials or executable.

1. Establish explicit authorization for the reviewed content and customer help-centre destination. Existing approval for that exact content and destination in the current task is sufficient.
2. Compare the reviewed local file with the current preview. If content has changed materially since approval, obtain approval for that content before writing.
3. Submit once using the supported publisher. Record its content revision and destination.
4. Verify the destination and published revision by reading back.
5. If submission fails or times out, inspect the destination and revision first. Retry only after establishing that no write occurred. If state or destination cannot be established, stop and ask the editor to decide.

This does not authorize email, note deletion, account changes or product changes.
