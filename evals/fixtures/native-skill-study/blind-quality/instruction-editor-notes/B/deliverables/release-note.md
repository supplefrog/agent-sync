# Quarry 2.4: Reuse your writing guidance with presets

If you write different kinds of drafts, you no longer have to recreate the same guidance each time. In Quarry 2.4, you can save named instruction presets and choose one when starting a new draft.

To try it, create a New preset with a name and the guidance you want to reuse, then select it for a new draft. You can also Duplicate a preset to make an independent variation; changes to the original won't change the copy. If you already had default guidance, you'll find it in a preset called **My default**. A preset can have no instruction text if you want to start without custom guidance.

Your drafts already in progress keep their content and prior guidance. Updating Quarry, choosing another preset, or editing one won't rewrite them. A draft's preset label records which preset it started with; it doesn't necessarily reflect that preset's current text.

Presets are saved on this device only. They don't sync to other devices in 2.4, so copy the preset text manually if you want to use it elsewhere.

Quarry 2.4 is available to all desktop users after updating.
