# Quarry 2.4: Keep your writing guidance ready for the next draft

If you use different guidance for different kinds of writing, you can now save it as named instruction presets and choose a preset when starting a new draft. No need to rewrite the same guidance each time.

To try it, update your desktop app and create a **New preset** with a name and the guidance you want to reuse. Then select it for a new draft. You can also **Duplicate** a preset to make an independent variation; editing the original later won't change the copy. Your existing default guidance is available as a preset named **My default**. It's also fine to leave a preset's instruction text empty if you want to start without custom guidance.

Presets guide new drafts; changing your selection, editing a preset, or updating Quarry won't rewrite drafts already in progress. A draft's preset label records what it started with, not necessarily the preset's current text.

Presets stay on the device where you create them. Quarry 2.4 does not sync them between devices, so if you work on another device, you'll need to copy your preset text manually.
