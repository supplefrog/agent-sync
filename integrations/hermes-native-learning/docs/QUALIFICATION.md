# Qualification and remaining acceptance

## What source controls establish

Portable controls execute the real file adapter and command wrapper in synthetic temporary stores. They cover configuration/caller refusal, initial plan approval, committed prediction, answer save/replay rejection, one continuation claim, explanation, check feedback, reopen, hidden practice solution, thinking, feedback, conclusion and explicit Next. They do not establish actual model quality, SDK loading, real caller identity, native answer delivery or learning outcomes.

The reused SDK seam has separately retained synthetic controls for immutable projections, digest validation, owner binding, long input, stale drafts and draft replacement during delivery. Cross-window draft writes are not atomic. A previous native Resume mechanism was observed separately; it is not a live qualification of this packaged contribution.
